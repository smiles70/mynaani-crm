# Stage 3 — failure + edge analysis (30/30) — magiclink signin

## 30 FAILURE CASES (F1–F30)

### Token/link lifecycle (F1–F10)
| # | Trigger | Impact | Remediation |
|---|---|---|---|
| F1 | Token expires before click (TTL) | UX | 600s TTL; "request a new link" copy |
| F2 | Token used twice | security | library consumes atomically (verified src) |
| F3 | Replay within TTL (forwarded link) | security | single-use consume + short TTL |
| F4 | Token for email A verified as email B | security | token bound to email in stored record |
| F5 | Cross-purpose token (OAuth state reused) | security | namespaced verification record (GHSA fix in 1.6.x) |
| F6 | Concurrent requests race the consume | functional | atomic consume — one wins, other INVALID_TOKEN |
| F7 | Scanner prefetch burns token | **functional+critical** | documented residual; emailOTP fallback; copy tells user to re-request |
| F8 | User requests 2 links, clicks first | functional | newest-invalidates-older per Auth0 pattern; better-auth stores last token |
| F9 | verify called manually via API w/o callback | functional | callbackURL required in signIn.magicLink call |
| F10 | Token entropy insufficient | security | library 32-char random ≥128bit |

### Allow-list/gating (F11–F16)

| F12 | Allowlisted email → hook passes → user created | functional | desired path |
| F13 | Domain spoof "zack@sharkwheel.com.evil.com" | security | hook uses exact-domain match (verify isWorkspaceEmail) |
| F14 | Email case differences (Zack@) | functional | normalize_email — better-auth lowercases |
| F15 | ALLOWED_SIGN_IN env typo'd empty | functional | hasSignInAllowList() false → FORBIDDEN everyone — env must stay set |
| F16 | User deleted, stale link still valid | security | verify recreates? — verify-time hook re-checks |

### Mail delivery (F17–F22)
| F17 | RESEND_API_KEY unset | functional | honest log; UI shows generic success (can't leak) but nothing arrives → ops monitor |
| F18 | From-domain unverified in Resend | functional | Resend rejects send → log; preflight must verify domain |
| F19 | DMARC/SPF mismatch to sharkwheel.com MX | deliverability | verified-domain sender; check sharkwheel MX isn't filtering |
| F20 | Email lands in spam/junk | deliverability | transactional subdomain recommendation (residual) |
| F21 | Send is slow (>30s) | UX | async fire-and-forget OK — sendMagicLink awaited by endpoint; keep <5s timeout |
| F22 | Resend outage | availability | error log; user retries |

### Integration/UI (F23–F27)
